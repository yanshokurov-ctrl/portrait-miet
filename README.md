# Портрет личности

Программный модуль для определения личностных характеристик человека по 20 методикам.
Учебная практика ПМ.01, Колледж ЭИ МИЭТ, 2026.

План работы — [PLAN.md](PLAN.md). Что сделать команде сейчас — [TODO.md](TODO.md). Контракт методики — [docs/contract.md](docs/contract.md). Формат JSON-методик и ключей — [docs/method_format.md](docs/method_format.md). Обработка ошибок — [docs/errors.md](docs/errors.md).

## Запуск

Нужен Python 3.11 или новее. Сторонние библиотеки не используются.

```bash
python main.py
```

Программа проводит респондента по всем 20 методикам из `portrait/methods/data` (499 вопросов). Каждая методика — отдельный тест: перед ним показываются «Методика N из 20» и инструкция (название методики по ТЗ не показывается). После всех методик программа показывает «Портрет личности» и сохраняет его в `portrait.json`. Если опрос прерван, результат не сохраняется.

Как отвечать: ввести номер варианта, число или текст — в зависимости от вопроса. Команды:

| Команда | Действие |
|---|---|
| `н` | Назад к предыдущему вопросу — прежний ответ будет показан, ответить нужно заново |
| `з` | Завершить опрос и получить результат — доступно только после прохождения всех методик |
| `?` | Помощь |

Параметры:

```bash
python main.py --out результат.json --respondent student-01 --data путь/к/методикам
```

- `--out` — куда сохранить отчёт (по умолчанию `portrait.json`);
- `--respondent` — id респондента (по умолчанию создаётся анонимный);
- `--data` — папка с JSON-методиками (по умолчанию `portrait/methods/data`).

Тесты:

```bash
python -m unittest
```

## Структура

```
portrait/
  core/
    models.py       # модели данных: Question, Answer, MethodResult, Portrait
    contracts.py    # контракт методики MethodBlock, справочник 20 методик, правило статуса
    engine.py       # движок опроса SurveySession
    collector.py    # сборщик результатов: collect() и текстовый отчёт to_text()
    errors.py       # исключения модуля
  sources/          # источники вопросов (JSON, позже база данных)
  methods/
    json_method.py  # методика из JSON-файла
    scoring.py      # подсчёт баллов по ключам
    data/           # 20 методик: вопросы, инструкции, ключи (m01.json … m20.json)
  ui/
    console.py      # консольный интерфейс опроса
tests/              # автотесты (unittest)
docs/               # документация
main.py             # точка входа
```

## Договорённости

- **Python 3.11+, только стандартная библиотека.** Ничего не ставим через pip.
- **Имена** переменных, функций, классов и файлов — на английском. **Комментарии и docstring** — на русском.
- Стиль кода — PEP 8: отступ 4 пробела, `snake_case` для функций и переменных, `CamelCase` для классов.
- Каждая функция и класс — с коротким docstring: что делает, что принимает, что возвращает.
- Код пишем понятно для всей команды: без «хитрых» конструкций, лучше длиннее, но очевиднее.
- **Git:**
  - в `main` напрямую не коммитим;
  - каждая задача — своя ветка: `имя/кратко-о-задаче`, например `ivan/engine-navigation`;
  - изменения попадают в `main` через pull request после ревью основного разработчика;
  - перед pull request запускаем `python -m unittest` — все тесты должны проходить.
- Сообщения коммитов — на русском, в повелительном наклонении: «Добавь проверку ответа», «Исправь подсчёт пропусков».
