## Общие правила

- **Формат:** Markdown (`.md`), папка `docs/`. Язык — русский, стиль — как в уже написанных документах: короткие абзацы, таблицы, примеры.
- **Пишем только то, что есть в коде.** Каждое утверждение проверяйте: запустите программу, посмотрите код или docstring. Если в коде и документе расходятся — сообщите основному разработчику, не «подгоняйте» текст.
- **Примеры — настоящие.** Вывод консоли и JSON копируйте из реального запуска, а не придумывайте.
- **Короткий опрос для примеров.** Чтобы не отвечать на 499 вопросов, запускайте на тестовых методиках (3 методики по 3 вопроса):
  ```bash
  python main.py --data tests/fixtures/methods --out пример.json
  ```
  Ответы для полного прохождения: `1`, `2`, `3`, `1`, `4`, `3`, `2`, `1`, любой текст, затем `з`.
- **Не путать документы для разных читателей:** респонденту — инструкции и руководство пользователя; команде и преподавателю — архитектура, API, форматы.
- **Как сдавать:** ветка `<имя>/docs-<что>`, например `anna/docs-api`, затем pull request в `main`. Ревью делает основной разработчик.

### 1.2. `docs/api.md` — функции модуля

Читатель: команда этапа 3 (интерфейс, валидатор), преподаватель (обёртка для тестирования). Это главный документ для тех, кто будет вызывать модуль из своего кода.

Для каждой функции: что делает, параметры, что возвращает, какие исключения выбрасывает, короткий пример.

- [ ] **Источник вопросов:** `JsonSource(папка)`, `load_methods()`; ошибка `SourceError`.
- [ ] **Движок `SurveySession`:**
  - создание: `SurveySession(методики)`; ошибка `SessionError`;
  - текущее состояние: `current_question()`, `current_answer()`, `current_method()`, `progress()`, `method_progress()`, `is_finished()`;
  - действия: `answer(value)`, `back()`, `next()`, `skip()`; ошибки `InvalidAnswerError`, `SessionError`. Отметьте: в консоли `skip()` и `next()` не используются — респондент обязан ответить на каждый вопрос;
  - результат: `grouped_answers()`, `finish()`.
- [ ] **Сборщик:** `collect(результаты, respondent_id)`, `to_text(портрет)`, `validate_result(результат)`.
- [ ] **Модели:** `Question`, `Answer`, `MethodResult`, `ScaleScore`, `Portrait` (`to_json()`, `from_json()`, `summary()`, `get()`) — коротко, со ссылкой на `contract.md`, где они описаны подробно.
- [ ] **Полный пример** — опрос от загрузки до отчёта в 10–15 строк кода. Образец — функция `run()` в `portrait/ui/console.py`.
- [ ] **Запуск из командной строки:** `python main.py` и параметры `--out`, `--respondent`, `--data`; коды завершения 0 и 1.

**Откуда брать:** docstring каждой функции — в них уже описано поведение и ошибки; `README.md`.
**Проверка:** пример кода из документа должен запускаться без ошибок.

### 1.3. `docs/portrait_format.md` — формат итогового отчёта

Читатель: команда этапа 3 (экран результатов), психологи, преподаватель.

- [ ] Структура JSON «Портрета»: поля `respondent_id`, `created_at`, `summary`, `results`, `warnings` — таблица «поле → тип → описание».
- [ ] Структура результата методики: `method_id`, `method_name`, `status`, `scores`, `interpretation`, `answered`, `total`, `errors`.
- [ ] Статусы `ok`, `partial`, `error`, `no_data` — когда какой ставится (есть в `docs/errors.md`, раздел «Правило статуса»).
- [ ] Правила сборщика: в отчёте всегда 20 методик в порядке справочника; что происходит с дублями, неизвестными методиками, неверным форматом.
- [ ] **Примеры JSON** (сократите до 2–3 методик, остальное — `…`):
  - все методики пройдены — возьмите из `пример.json` после короткого опроса;
  - методика не прислала результат — `no_data` «Результат не получен» (есть в том же файле: методики 4–20);
  - методика упала — `error` с причиной (пример можно взять из тестов `tests/test_collector.py`).
- [ ] Пример текстового отчёта — то, что печатает консоль после опроса.

**Откуда брать:** `portrait/core/models.py`, `portrait/core/collector.py`, реальный `пример.json`.

### 1.4. `docs/scenarios.md` — как респондент проходит опрос

Читатель: тестировщики, преподаватель, будущее «Руководство пользователя».

Каждый сценарий: шаги пользователя → что он видит (фрагмент вывода консоли) → результат.

- [ ] **Полное прохождение:** запуск → «Методика 1 из N» и инструкция → вопросы → «Все методики пройдены» → `з` → отчёт и файл `portrait.json`.
- [ ] **Неверный ответ:** ввод `7` или текста вместо номера → сообщение → тот же вопрос снова.
- [ ] **Возврат назад:** `н` → показан прежний ответ → нужно ответить заново.
- [ ] **Попытка завершить раньше времени:** `з` до конца опроса → отказ.
- [ ] **Возврат с экрана «Все методики пройдены»:** `н` → последний вопрос.
- [ ] **Прерывание:** Ctrl+C → «Опрос прерван», результат не сохраняется.
- [ ] **Ошибка загрузки методик:** `python main.py --data несуществующая_папка` → сообщение, код 1.

**Откуда брать:** запуск программы на тестовых методиках; тесты `tests/test_console.py` — в них описаны те же сценарии.
