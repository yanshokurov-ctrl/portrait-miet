# Формат JSON-методики

Каждая методика — один файл `portrait/methods/data/mNN.json`. Загружает его `JsonMethod` ([portrait/methods/json_method.py](../portrait/methods/json_method.py)), баллы считает [portrait/methods/scoring.py](../portrait/methods/scoring.py).

Все 20 методик перенесены из исходных документов (вопросы, инструкции, ключи). Правильность ключей проверяет [tests/test_methods_data.py](../tests/test_methods_data.py): на известные ответы баллы сверяются с ключами и диапазонами из документов.

## Структура файла

```json
{
  "method_id": "m02",
  "instruction": "Прочтите каждое утверждение и определите…",
  "type": "scale",
  "options": [
    {"value": 1, "label": "Совсем не согласен"},
    {"value": 5, "label": "Полностью согласен"}
  ],
  "questions": [
    {"text": "В целом я доволен собой"},
    {"text": "Свой вопрос", "type": "choice", "options": [{"value": "а", "label": "…"}]}
  ],
  "scoring": { "…": "см. ниже" }
}
```

| Поле | Обязательно | Что это |
|---|---|---|
| `method_id` | да | id из справочника `METHODS` (`m01`…`m20`) |
| `instruction` | нет | Инструкция для респондента — показывается перед вопросами методики |
| `type` | нет | Тип вопросов по умолчанию: `scale`, `choice`, `number`, `text` |
| `options` | нет | Варианты ответа по умолчанию — для всех вопросов методики |
| `questions` | да | Список вопросов. У вопроса обязателен `text`; `type` и `options` можно задать свои |
| `scoring` | нет | Ключи. Если нет — временный подсчёт: сумма числовых ответов |

id вопросов (`m02_q01`), `method_id` и `order` в файле не пишутся — их проставляет загрузчик по порядку.

**По ТЗ** в инструкции и вопросах не должно быть названия методики и её авторов. Это проверяет тест `test_no_method_names_in_test_text`.

### Значение ответа = балл

Для шкальных вопросов `value` варианта — это сразу его балл. Например, в методике 7 подписи вариантов «−3 … 3», как в бланке, а значения — баллы 0…6 по прямой шкале. В методике 10 «Да» = 2, «Иногда» = 1, «Нет» = 0.

## Ключи: раздел `scoring`

```json
"scoring": {
  "reverse_base": 6,
  "note": "Пояснение — добавится к выводу по методике",
  "scales": [ … ],
  "interpretation": { … }
}
```

Номера вопросов в ключах — порядковые номера вопросов методики, с 1 (как в документе методики).

### Виды шкал

**1. Сумма (или среднее) по пунктам** — для числовых ответов.

```json
{"name": "Самооценка", "items": [1, 2, 3, 4], "reverse": [2, 3, 4]}
{"name": "Мотивы престижа", "items": [8, 9, 29, 30, 34], "aggregate": "mean"}
```

- `reverse` — обратные пункты: балл = `reverse_base` − ответ. `reverse_base` = минимум + максимум шкалы (для 1…5 это 6, для 1…7 — 8, для 0…6 — 6).
- `aggregate`: `sum` (по умолчанию) или `mean` — среднее, округляется до 2 знаков.

**2. Совпадение с ключом** — 1 балл за каждый ответ, совпавший с ключом.

```json
{"name": "Шкала лжи", "key": {"6": "да", "12": "да", "18": "да"}}
```

**3. Составная** — сумма и разность шкал, объявленных выше.

```json
{"name": "Общий показатель ЭИ (ОЭИ)", "plus": ["Внутриличностный ЭИ (ВЭИ)", "Межличностный ЭИ (МЭИ)"]}
{"name": "Индекс общей адаптивности (ИОАД)", "plus": ["Индекс общей активности (ИОА)"], "minus": ["Индекс общей эмоциональности (ИОЭ)"]}
```

### Интерпретация

Сейчас поддерживается один вид — доминирующая шкала (методика 14):

```json
"interpretation": {"type": "dominant", "scales": ["…", "…"], "min": 4, "title": "Доминирующий стиль коммуникации"}
```

Несколько шкал с одинаковым наибольшим баллом — «совмещаются»; один лидер ниже `min` — «не выражен».

### Пропуски

Пропущенные вопросы в подсчёт не попадают: сумма считается по отвеченным пунктам. Статус методики (`ok` / `partial` / `no_data`) — по общему правилу из [errors.md](errors.md).

## Проверка при загрузке

`JsonMethod` проверяет ключи сразу при загрузке и при ошибке не даёт запустить опрос (сообщение с именем файла):

- номера вопросов существуют, пункты не повторяются;
- обратные пункты входят в `items`, задан `reverse_base`;
- у пунктов сумм варианты ответа — числа;
- значения в `key` есть среди вариантов ответа вопроса;
- составные шкалы ссылаются на шкалы, объявленные выше.
