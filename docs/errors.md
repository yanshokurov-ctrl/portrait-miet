# Обработка ошибок

Как модуль реагирует на ошибки и нештатные ситуации. Исключения — [portrait/core/errors.py](../portrait/core/errors.py).

Главный принцип: **сбой одной методики не ломает опрос и отчёт.** Пользователь проходит опрос до конца, а проблемная методика получает в отчёте статус `error` или `no_data` с причиной.

## Таблица реакций

| Ситуация | Где ловится | Что делает модуль | Что видит пользователь |
|---|---|---|---|
| Недопустимый ответ (нет такого варианта, не число) | движок, консоль | `InvalidAnswerError`; ответ не сохраняется, вопрос остаётся тем же | «! Введите номер варианта от 1 до 3» — и тот же вопрос снова |
| Недопустимое действие (назад с первого вопроса) | движок | `SessionError`; ничего не меняется | Сообщение и тот же вопрос снова |
| Методика не отдала вопросы (`get_questions()` упал или вернул неверные данные) | движок | `BlockError` внутри движка; вопросы методики не показываются | Опрос идёт дальше; в отчёте у методики «ошибка» с причиной |
| Методика упала при подсчёте (`process()` выбросил исключение) | движок | Статус `error` с текстом исключения; остальные методики считаются | В отчёте у методики «ошибка» с причиной |
| Методика вернула не `MethodResult` или результат чужой методики | движок | Статус `error` | В отчёте у методики «ошибка» с причиной |
| Результат в неверном формате (испорченные поля) | сборщик | `InvalidResultError` внутри сборщика; статус `error` + предупреждение | «ошибка» у методики и строка в «Предупреждениях» |
| Повторный результат одной методики | сборщик | Оставляется первый, второй отбрасывается + предупреждение | Строка в «Предупреждениях» |
| Результат неизвестной методики (нет в справочнике) | сборщик | Отбрасывается + предупреждение | Строка в «Предупреждениях» |
| Методика не прислала результат | сборщик | Статус `no_data` «Результат не получен» | Методика в списке «Нет данных» |
| Пропущено больше половины вопросов методики | методика (`result_status`) | Статус `no_data` с пояснением | Методика в списке «Нет данных» |
| Пропущена часть вопросов, но отвечено не меньше половины | методика (`result_status`) | Статус `partial`, результат считается по отвеченным | «частично» и пометка «результат приблизительный» |
| Источник вопросов недоступен (нет папки, битый JSON, неизвестный `method_id`) | источник | `SourceError`; опрос не запускается | «Не удалось загрузить методики: …» с именем файла; программа завершается с кодом 1 |
| Нет ни одной методики | движок | `SessionError`; опрос не запускается | «Не удалось загрузить методики: Нет ни одной методики для опроса» |
| Пользователь пытается завершить опрос (команда «з») до прохождения всех методик | консоль | Команда отклоняется, вопрос остаётся тем же | «! Завершить опрос можно только после того, как пройдены все методики» |
| Опрос прерван (Ctrl+C, закрыт ввод) | консоль | Опрос завершается, результат **не** сохраняется; программа завершается с кодом 1 | «Опрос прерван. Результат не сохранён: опрос нужно пройти до конца.» |
| Не удалось сохранить отчёт в файл | консоль | Отчёт показан на экране, программа завершается с кодом 1 | «Не удалось сохранить результат в …» |

## Правило статуса по пропускам

Общее для всех методик правило — `result_status(answered, total)` в [portrait/core/contracts.py](../portrait/core/contracts.py):

| Отвечено | Статус |
|---|---|
| Все вопросы | `ok` |
| Не меньше `MIN_ANSWERED_SHARE` (сейчас 50%) | `partial` |
| Меньше 50% или ни одного | `no_data` |

Пропущенные вопросы (`Answer.skip`) и непройденные (`None`) отвеченными не считаются.

Порог 50% — предварительный. Его нужно согласовать с командой на этапе 2, когда станут известны методики: для некоторых методик даже один пропуск может делать результат недостоверным.

## Исключения

| Исключение | Когда | Выходит наружу? |
|---|---|---|
| `PortraitError` | Базовое для всех — интерфейс ловит любую ошибку модуля через `except PortraitError` | — |
| `SourceError` | Источник вопросов недоступен или данные повреждены | Да — из `load_methods()` |
| `SessionError` | Недопустимое действие в опросе; опрос без методик | Да — из методов `SurveySession` |
| `InvalidAnswerError` | Ответ не подходит к вопросу | Да — из `SurveySession.answer()` |
| `BlockError` | Методика нарушила контракт при выдаче вопросов | Нет — движок превращает в статус `error` |
| `InvalidResultError` | Результат методики в неверном формате | Нет — сборщик превращает в статус `error` |
